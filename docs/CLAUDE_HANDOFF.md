# Claude Handoff: PR Monitor

Этот файл нужен для быстрой передачи проекта другому агенту без погружения в длинную историю чата.

## 1. Что это за проект

PR Monitor — SaaS-платформа для медиамониторинга:

- проекты мониторинга и поисковые запросы;
- сбор упоминаний из RSS, Google News, GDELT, Serper, Yandex Search, VK и других источников;
- дашборд, ИИ-анализ, Excel-экспорт;
- многопользовательский режим, роли, регистрация, восстановление пароля;
- коммерческий слой: тарифы, платежи, доступы.

## 2. Главные папки

- `mention_monitor/` — основная логика приложения;
- `tests/` — автотесты;
- `deploy/` — развёртывание;
- `relay/` — вспомогательные relay-компоненты;
- `site/` — внешний маркетинговый сайт и связанные статические материалы.

## 5. Доступы

В репозиторий пароли и ключи не кладём.

Что должно передаваться отдельно владельцем:

- root-доступ к серверу;
- пароль или SSH-ключ;
- доступ к панели домена/DNS;
- рабочие API-ключи внешних сервисов.

Что уже хранится вне git:

- `.env`
- `data/secrets.json`
- `data/mentions.db`
- `data/raw/`

## 7. Деплой

Основной сценарий на сервере:

```bash
cd /opt/pr-monitor
docker compose up -d --build
```

Если нужен только пересбор веба и воркера:

```bash
cd /opt/pr-monitor
docker compose up -d --build app worker
```

Проверка статуса:

```bash
cd /opt/pr-monitor
docker compose ps
docker compose logs --tail=100 app
docker compose logs --tail=100 worker
```

## 8. Что важно знать перед изменениями

1. Не трогать `data/` и секреты при git-операциях.
2. Перед большими правками сначала смотреть:
   - `mention_monitor/pages.py`
   - `mention_monitor/webapp.py`
   - `mention_monitor/collector.py`
   - `mention_monitor/db.py`
   - `mention_monitor/analysis.py`
3. После изменений прогонять тесты:

```bash
python3 -m unittest discover -s tests
```

4. После источниковых правок отдельно проверять:
   - фильтрацию по дате;
   - дедупликацию;
   - тональность;
   - релевантность;
   - экспорт Excel.

## 9. Текущие интеграции и особенности

- Google в проекте обычно идёт через Serper, а не через прямой Google API.
- VK подключается токеном и периодически требует проверки.
- Yandex Search и YandexGPT используются как отдельные провайдеры.
- Claude тоже поддержан как AI-провайдер.
- В проекте есть SMTP-функции для регистрации, подтверждения почты и восстановления пароля.

## 10. Что особенно важно не сломать

- логин/регистрация/восстановление пароля;
- админку и роли;
- проектные фильтры и дашборд;
- корректность дат публикаций;
- многопользовательский доступ;
- коммерческие ограничения по тарифам.

## 11. Git-правила для этого проекта

- не коммитить секреты;
- не коммитить `data/mentions.db`, `data/raw`, резервные копии и локальные архивы;
- отдельные осмысленные коммиты под отдельные задачи;
- перед деплоем смотреть `git status`, чтобы не утащить случайные локальные файлы.
