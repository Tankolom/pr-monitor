# Такт — музыка для выступления ровно нужной длины

Веб-сервис: пользователь загружает трек и указывает длительность (например, 1:30), сервис
автоматически сокращает или удлиняет музыку по тактам, сохраняя финал, и выдаёт 3 варианта.
Прослушивание бесплатно (превью с тихим водяным знаком), выбранный вариант — 490 ₽,
пакет из 5 треков — 1490 ₽. Оплата — ЮKassa (карта, СБП).

Для кого: художественная гимнастика, фигурное катание, танцы, выпускной вальс, первый свадебный танец.

## Что внутри

```
app/
  audio/            движок
    io.py           декодирование/кодирование (ffmpeg), смена темпа (Rubber Band)
    analysis.py     доли и такты (нейросеть Beat This! + очистка + Витерби для сильных долей),
                    признаки тактов (хрома, MFCC, громкость), матрица похожести
    planner.py      выбор склеек: динамика по тактам (1–3 прыжка), «похожесть» и «границы разделов»,
                    удлинение повтором, финал с затуханием, 3 разных варианта
    render.py       склейка с подстройкой фазы и кроссфейдом, точная длительность, громкость −14 LUFS,
                    сигнал перед музыкой, водяной знак для превью, пики для волны
    pipeline.py     полный цикл «файл → 3 варианта + meta.json», экспорт MP3 320 / WAV
  main.py           HTTP API, страницы, скачивание, вебхук ЮKassa, тестовая оплата
  services.py       задания, заказы, пакеты, разблокировка, пересборка, очистка
  worker.py         обработчик очереди (отдельный процесс)
  payments/         ЮKassa и mock
  db.py             SQLite (WAL)
  admin.py          /admin — воронка, выручка, оценки, ошибки
static/             лендинг + приложение (без сборки), оферта, политика
eval/               оценка качества склеек, слепой тест для тренеров
tests/              автотесты (движок на синтетической песне, API, оплата)
```

## Локальный запуск

Нужны Python 3.11, ffmpeg, rubberband-cli.

```bash
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements.txt
export DATA_DIR=./data PAYMENT_PROVIDER=mock ADMIN_TOKEN=dev
uvicorn app.main:app --reload --port 8000 &     # сайт: http://localhost:8000
python -m app.worker                            # обработчик очереди
```

С `PAYMENT_PROVIDER=mock` оплата имитируется страницей «Оплатить (тест)».

## Тесты

```bash
pip install pytest playwright
python -m pytest tests -q                 # движок + API + оплата
python tests/e2e_ui.py                    # сквозной сценарий в браузере (нужны запущенные сервер и воркер)
```

## Проверка качества на своих треках

```bash
python -m eval.run_eval --music ./tracks --out ./eval_out --targets 90,150
# eval_out/summary.md — сводка; eval_out/*/v*_seam*.png — спектрограммы вокруг склеек
python -m eval.blind ./eval_out ./blind_test     # страница слепого теста для тренеров
python -m eval.blind score ./blind_test/key.json results.csv
```
