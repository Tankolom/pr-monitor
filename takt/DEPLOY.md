# Развёртывание «Такт» на своём сервере

Примерное время — 1–2 часа, если домен и ЮKassa уже есть. Всё, что ниже в `моноширинном` шрифте, копируется в терминал сервера.

## 0. Что понадобится (разово)

| Что | Где | Примерно |
|---|---|---|
| Сервер в РФ, 4 vCPU / 8 ГБ ОЗУ / 40 ГБ диска, Ubuntu 22.04 или 24.04 | Timeweb Cloud, Selectel, REG.RU и т. п. | 2–3 тыс. ₽/мес (проверьте актуальные тарифы) |
| Домен .ru | любой регистратор | 200–900 ₽/год |
| Статус самозанятого или ИП | приложение «Мой налог» / Госуслуги | 0 ₽ |
| Магазин в ЮKassa | yookassa.ru → «Подключиться» | 0 ₽ + комиссия с платежей |
| Почта на домене (по желанию) | Яндекс 360 и т. п. | 0–300 ₽/мес |
| Счётчик Яндекс Метрики (по желанию) | metrika.yandex.ru | 0 ₽ |

Серверы в РФ нужны и из-за закона о персональных данных (152-ФЗ, локализация), и для скорости у российских пользователей.

## 1. Сервер

1. Создайте сервер (Ubuntu 24.04), скопируйте его IP-адрес.
2. У регистратора домена добавьте две A-записи: `@` → IP сервера и `www` → IP сервера. DNS обновится за 5–60 минут.
3. Подключитесь к серверу: `ssh root@IP`, затем установите Docker:

```bash
curl -fsSL https://get.docker.com | sh
```

## 2. Код и настройки

```bash
git clone <адрес вашего репозитория> takt-src
cd takt-src/takt
cp .env.example .env
nano .env
```

В `.env` обязательно заполните: `DOMAIN`, `BASE_URL`, `ADMIN_TOKEN` (длинная случайная строка), реквизиты
(`SELLER_NAME`, `SELLER_INN`, `SELLER_STATUS`, `CONTACT_EMAIL`). Для первого запуска оставьте
`PAYMENT_PROVIDER=mock` — проверите всё без денег.

## 3. Запуск

```bash
docker compose up -d --build
docker compose logs -f web worker     # выход: Ctrl+C
```

Первая сборка — 5–10 минут (ставится нейросеть). Caddy сам получит HTTPS-сертификат. Откройте `https://ваш-домен`:
загрузите любой трек, дождитесь вариантов, нажмите «Выбрать» → «Оплатить (тест)» → скачайте файл.
Статистика: `https://ваш-домен/admin?token=ВАШ_ADMIN_TOKEN`.

Два обработчика очереди на 4 ядрах (быстрее при наплыве): `docker compose up -d --scale worker=2`.

## 4. ЮKassa

1. Подключите магазин на yookassa.ru. Самозанятым: при подключении выберите статус самозанятого — ЮKassa
   подскажет, как формируются чеки в «Мой налог» (уточните в личном кабинете, условия меняются). ИП/ООО: подключите
   «Чеки от ЮKassa» и поставьте в `.env` `YOOKASSA_SEND_RECEIPT=1` — тогда при оплате обязателен e-mail.
2. Сначала создайте **тестовый магазин** (в кабинете ЮKassa есть переключатель «Тестовый магазин»). Возьмите его
   `shopId` и секретный ключ (Интеграция → Ключи API).
3. В `.env`:
   ```
   PAYMENT_PROVIDER=yookassa
   YOOKASSA_SHOP_ID=...
   YOOKASSA_SECRET_KEY=...
   ```
4. В кабинете ЮKassa: Интеграция → HTTP-уведомления → URL `https://ваш-домен/api/payments/yookassa`, события
   `payment.succeeded` и `payment.canceled`.
5. Перезапустите: `docker compose up -d`. Оплатите тестовой картой из документации ЮKassa, убедитесь, что файл
   открылся и в `/admin` появилась оплата.
6. Замените ключи на боевые, перезапустите, сделайте одну реальную покупку за свои деньги и верните её себе через кабинет.

Даже если уведомление от ЮKassa не придёт, страница после оплаты сама спросит статус платежа у ЮKassa —
покупатель получит файл. Уведомлению сервер не доверяет вслепую: статус всегда перепроверяется через API.

## 5. Почта (по желанию)

Для писем со ссылками и кодами пакетов заполните `SMTP_*` и `MAIL_FROM` (для Яндекс 360 — `smtp.yandex.ru`, порт 465,
пароль приложения). Без почты всё работает: ссылки показываются на странице.

## 6. Обслуживание

* Обновление: `git pull && docker compose up -d --build`.
* Резервная копия базы (заказы, коды пакетов) раз в день:
  ```bash
  crontab -e
  # добавьте строку:
  15 4 * * * docker compose -f /root/takt-src/takt/docker-compose.yml exec -T web python -c "import sqlite3;s=sqlite3.connect('/data/takt.sqlite3');d=sqlite3.connect('/data/backup.sqlite3');s.backup(d)" && docker cp $(docker compose -f /root/takt-src/takt/docker-compose.yml ps -q web):/data/backup.sqlite3 /root/takt-backup-$(date +\%a).sqlite3
  ```
* Аудиофайлы удаляются автоматически через `RETENTION_DAYS` дней.
* Проверка живости: `https://ваш-домен/healthz` (можно поставить бесплатный мониторинг, например UptimeRobot).
* Если трек «завис»: `docker compose restart worker` — задание вернётся в очередь.

## 7. Если что-то не так

| Симптом | Что сделать |
|---|---|
| Сайт не открывается по HTTPS | Проверьте A-записи домена и что порты 80/443 открыты; `docker compose logs caddy` |
| Треки долго в очереди | `docker compose logs worker`; добавьте обработчик `--scale worker=2` |
| Оплата не проходит | `docker compose logs web | grep -i yookassa`; проверьте ключи и режим (тестовый/боевой) |
| Письма не приходят | Проверьте `SMTP_*`; ошибки в `docker compose logs web` |
