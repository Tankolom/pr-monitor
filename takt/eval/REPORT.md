# Проверка качества движка (28.09.2026)

## Набор

16 треков под лицензиями Creative Commons и в общественном достоянии с archive.org (netlabels, Musopen):
поп, рок (в т. ч. 6/8), электроника, джаз (в т. ч. живой со «плавающим» темпом), вальсы (3/4, в т. ч.
запись с 78 оборотов), Шопен (рубато). Длительность 2:30–6:40. Каждый трек сокращён до **1:30** и до **2:30**
(один короткий трек — удлинён/подогнан темпом): 32 прогона, 90 вариантов. Сами треки в репозиторий не
входят (лицензии ND), список и ссылки — в `eval/tracks.md`.

## Как мерили

* **Точность длительности** — длина файла против заказанной.
* **Ритм на стыке** (`eval/objective.py`) — нейросеть ищет доли в готовом файле; сетку долей до стыка
  продлеваем за стык и меряем, насколько первые доли после него «промахиваются» (в долях: 0 — идеально,
  0.5 — сбой на полдоли). Контроль — та же метрика в случайных местах без склеек: медиана 0.02–0.07.
  Порог «подозрительно» — 0.2.
* **Спектрограммы** ±3 с вокруг каждого стыка — визуальная проверка двойных атак и провалов.

Слух автоматическая проверка не заменяет — поэтому перед рекламой обязателен слепой тест у тренеров
(`eval/blind.py`, см. LAUNCH.md, шаг 1).

## Результаты

| Показатель | Значение |
|---|---|
| Прогоны без ошибок | 32 / 32 |
| Точность длительности | ±0.000 с во всех вариантах |
| Изменение темпа для точного попадания | 0–3.1 %, медиана ≈ 1 % |
| Стыки с ровным ритмом (≤ 0.2) | 75 из 82 измеренных (91 %) |
| Первый (рекомендуемый) вариант без подозрений | 28 / 32 |
| Хотя бы один чистый вариант | 30 / 32 |
| Время обработки на 4 vCPU без нагрузки | 29–52 с на трек 2:30–6:00 |

Оценки алгоритма по вариантам: «почти не слышно» — 15, «хорошая» — 63, «послушайте склейку» — 8,
«затухание» (запасной) — 4.

## Что не получилось

* **Живой джаз с очень неровным темпом (jazz_1)**: на 1:30 остался только вариант с затуханием, на 2:30 —
  все варианты помечены «Послушайте склейку». Сервис честно показывает это пользователю.
* **7 стыков с подозрением на сбой ритма** — в основном рубато (Шопен), свинг и рок 6/8. На свинге
  внутренняя самопроверка и полная проверка иногда расходятся (трекер путает сильную и слабую долю) —
  решить может только слух.
* Склейки на **границах разделов** (конец куплета → финальный припев) по тембру и гармонии заметнее
  обычного перехода между долями — это ожидаемо (так монтирует и звукорежиссёр), но насколько это
  приемлемо для выступления, покажет слепой тест.

## Что изменилось по ходу проверки

1. Шумные сильные доли нейросети → очистка долей + размер + Витерби для сетки тактов.
2. Одна «дальняя» склейка звучала случайно → динамика по тактам (1–3 склейки) и второй тип хорошего стыка —
   «граница раздела → граница раздела».
3. Сдвиги ритма на стыке → выравнивание по атакам (±70 мс) + самопроверка каждого стыка нейросетью
   с исправлением сдвигом на ±¼/½ доли; штраф за разный темп в точках склейки.

Воспроизвести: `python -m eval.run_eval --music <папка> --out <папка> --targets 90,150`.
