# PR Monitor

PR Monitor — веб-платформа для мониторинга упоминаний в СМИ, поиске, RSS-источниках и соцплощадках с дашбордом, проектами, ИИ-анализом, экспортом и базовой коммерческой логикой.

## Что уже есть

- многопользовательский вход и роли;
- проекты мониторинга с сохранением запросов и истории;
- сбор упоминаний из RSS, Google News, GDELT, Yandex Search, Google/Serper, VK и дополнительных источников;
- SQLite-база с дедупликацией и историей прогонов;
- дашборд с метриками, графиками, картой медиа-поля и лентой публикаций;
- ИИ-анализ через Claude / YandexGPT / Ollama;
- экспорт в Excel;
- админка, тарифы, регистрация, подтверждение почты и восстановление пароля;
- Docker-развертывание для локальной и серверной среды.

## Структура проекта

- `mention_monitor/` — основной код приложения;
- `tests/` — автотесты;
- `deploy/` — вспомогательные материалы для выкладки;
- `relay/` — relay-компоненты для внешних источников;
- `site/` — статические элементы сайта;
- `run.py` — точка входа для локального запуска.

## Быстрый локальный запуск

1. Подготовить окружение и зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Запустить приложение:

```bash
python3 run.py server --port 8765
```

3. Открыть в браузере:

```text
http://127.0.0.1:8765
```

## Docker-запуск

1. Создать `.env` на основе `.env.example`
2. Запустить:

```bash
docker compose up -d --build
```

## Основные файлы конфигурации

- `config.json` — структура проекта, источники, настройки приложения;
- `.env.example` — пример переменных окружения для контейнеров;
- `data/secrets.json` — рабочие ключи и токены на сервере или локально (не коммитится).

## Важно

- Папка `data/` не должна попадать в git: там база, сырые данные и секреты.
- Перед прод-выкладкой проверьте SMTP, публичный URL, платёжные настройки и внешние API-ключи.

## Полезные документы

- `DEPLOY.md` — развёртывание;
- `SHARE.md` — быстрый доступ и передача демо;
- `technical_spec.md` — описание продукта и требований.
